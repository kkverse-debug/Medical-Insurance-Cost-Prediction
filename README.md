# Medical Insurance Cost Prediction

This project predicts medical insurance charges using machine learning.

## Models Used

- Multiple Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regression
- Random Forest Regression

## Dataset

Medical Insurance Cost dataset containing information such as:

- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Insurance Charges

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Gradio

## Features

- Data analysis
- Exploratory Data Analysis
- Data preprocessing
- Correlation analysis
- Covariance analysis
- Multiple regression models
- Model comparison
- Best model selection
- Model saving using Joblib
- Gradio prediction interface
